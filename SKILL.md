## 1.Introduction

Tableflipper defines the conventions for requirements, architecture, and development work in a project.

- All documents live in `tableflipper/` at the root of the project. The sections below define the files of each area.
- A file or directory is created when there is first content for it.
- Before working on an area, read the documents that already exist for it.
- Do not write to a document before the user has agreed to the content.
